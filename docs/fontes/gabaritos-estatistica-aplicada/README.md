## O que encontramos

Os arquivos apresentam respostas finais, tabelas e gráficos quando necessários, além das alternativas das questões objetivas. Alguns exercícios dos capítulos 4, 5 e 6 têm links para resoluções em vídeo. Não há uma resolução escrita passo a passo para todos os itens. O capítulo 1, por exemplo, não lista resposta para o exercício 4.

Os títulos dos capítulos e as páginas dos exercícios correspondem ao livro fonte. A numeração do livro não deve ser usada isoladamente para associar uma resposta às aulas: o conteúdo aprovado foi decomposto e contém adaptações. É preciso comparar o enunciado, os valores e os subitens antes de preencher cada registro.

## Pendência confirmada

No gabarito do capítulo 2, página 6, a questão objetiva 8 tem resposta D. Essa alternativa corresponde a 140 funcionários no exercício do histograma da aula 7 (livro-aula-07-multipla-escolha-8), confirmando o cálculo já feito a partir do gráfico original. A solução antiga da aula indicava E / 160. A resposta D / 140 já foi integrada ao exercício e à rotina de preparação; a solução antiga permanece preservada para rastreabilidade.
